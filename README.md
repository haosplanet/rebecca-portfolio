# CM3070 Final Project

Hi! Welcome to my repository for the CM3070 Final Project. 

This repository contains all the code, models, and data processing workflows I built for my final year project. 

## Project Overview

The main aim of this project was to analyze data, build predictive models, and evaluate their performance. 

Key parts of the project include:
- **Data Preprocessing & Cleaning:** Handling raw dataset inputs, missing values, and feature preparation.
- **Exploratory Data Analysis (EDA):** Visualising data trends and key correlations.
- **Model Training & Building:** Implementing and tuning machine learning algorithms.
- **Evaluation:** Testing model accuracy, performance metrics, and generating results.
